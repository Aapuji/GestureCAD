# GestureCAD
A webapp in which you can use your hands to control move around and interact with a 3D virtual environment. Uses webcam. Currently supports
 - Moving by pinching with left hand and moving in x-y plane (parallel to computer screen)
 - Rotating by pinching with right hand and moving in x-y plane
 - Picking up and dropping items by grabbing and releasing with right hand
There is no physics at the moment.

This runs on virtual host.
